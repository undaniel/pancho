# Marketplace listing

Practical checklist to make the Pancho++ listing convert better. Screenshots and
GIFs are the single biggest lever: most users decide from the visuals, not the text.

## Listing copy

**Short description** (one line, shown next to the icon):

> Clean, format and transform text like Notepad++ — **148 commands**, regex tester, pipelines and macros.

**Categories:** `Formatters`, `Other`.
**Keywords:** notepad, text, format, sort, lines, regex, case, base64, csv, json, macro, pipeline, whitespace.

**Suggested highlights (first paragraph of the listing):**

- 146 one-click text operations, organized by category.
- Works on the selection or the whole document, multi-cursor aware.
- Diff preview before destructive changes.
- Pipelines: chain transforms, preview and save them.
- Privacy-first: **no telemetry**, everything runs locally.

## Notes

- Keep everything **theme-neutral**: capture in the default dark theme, which is
  what most users run.
- Do not include personal data in screenshots (paths, tokens, emails).
- Prefer the default font and the default layout; avoid custom themes that make the
  UI look like a different product.
