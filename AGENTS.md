# Pancho - VS Code Extension

## Modo de trabajo: Ponytail FULL

Antes de escribir código:
1. Buscar si ya existe una solución en el codebase
2. Verificar si realmente hace falta
3. Resolver con lo mínimo necesario

## Comandos útiles

- `npm run compile` - Compilar TypeScript
- `npm test` - Ejecutar tests
- `npm run package` - Empaquetar extensión

## Estructura

- `src/` - Código fuente
- `tests/` - Tests unitarios
- `dist/` - Compilado
