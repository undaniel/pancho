# Marketplace Assets

This directory contains visual assets required for the VS Code Marketplace listing.

## Required Assets

### 1. Banner (store-header.jpg)
- Size: 1280x640 pixels
- Shows the Pancho logo and tagline
- Used on the extension marketplace page header

### 2. Screenshots (screenshots folder)
Three screenshots demonstrating key features:

#### screenshot-1.gif
- Shows the context menu with all Pancho categories
- Demonstrates the organized submenu structure

#### screenshot-2.gif
- Shows a text transformation in action
- Example: sorting lines or converting case

#### screenshot-3.gif
- Shows the status bar counters in action
- Demonstrates countWords, countCharacters, countLines

## Current Icon

The extension currently has:
- `icon.png` - 256x256 pixels (small icon for VS Code)
- `icon-large.png` - 1024x1024 pixels (large icon for marketplace)

## Recommended Tools

To create these assets:
1. **Figma** - Free design tool for creating screenshots and banner
2. **LICEcap** - For creating animated GIF screenshots
3. **GIMP** - Free image editor

## Placeholder Setup

If you don't have design tools, you can:
1. Use the existing `pancho.webp` image as base
2. Create simple screenshots by:
   - Opening VS Code with the extension
   - Using LICEcap to record the screen
   - Saving as GIF in this folder
